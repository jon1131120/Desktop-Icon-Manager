> 实测模式：沙箱里真跑真测，不许纸上推演。每个工况贴「命令 + 真实输出 + ✅/❌/⚠️」。

## 沙箱环境说明
- **中枢 hub-server.py 是 Python，可直接沙箱真跑**：复制到 /tmp/sandbox_<你>/，改端口（如 18890/18891）起实例，全部工况在沙箱实例上测。
- **客户端 main.swift 是 Swift，可编译跑 CLI**：--selftest（40 点标定纯算法自检）。**变异测试**：改源码副本 → 重编译 → 跑 selftest，验证测试有效性（退回旧写法必须变红）。
- **真机零触碰**：不许 killall/open 三台真机的 QSpace Pro 与 QSpaceLayoutBar；不许写真机 ~/Library/Application Support/com.jinghaoshe.qspace.pro/desktop.conf；不许 POST 生产中枢 :18878（只许沙箱端口）；不许 ssh 到 air/studio/minipc 干扰。
- **沙箱场景必跑**（与上一条分开，两个独立要求）：下方 15 个工况在沙箱内全部真跑，逐条记预期 vs 实际。

## 15 个工况矩阵
1. **新增文件对账**：中枢 37 项、客户端 38 项（多 1）→ 对账补报 → 中枢变 38。验证补报条件与「死条目复活不补报」的分界。
2. **删除死条目清理**：中枢 38、客户端 37（少 1）→ 短缺计时 → 30 分钟（测试可注入缩短）→ 上报清理。验证「尊重删除」不提前补报。
3. **防震荡**：A 机报 38（含 X）、B 机报 37（无 X）交替 → 中枢名单不摇摆（X 曾在中枢 → 不补报）。
4. **快速连续变化**：客户端 conf 连续变更 5 次（间隔 <10s 防抖窗口）→ 只上报最终版，无中间态污染。
5. **QSpace 精简回写**：模拟 QSpace 把 conf 写成精简版（只留 visible+itemAttrs）→ 参数自愈补回 lod 等。
6. **conf 损坏**：写入坏 JSON → loadConf 拒绝 + 日志告警，同步暂停不崩。
7. **conf 缺失**：文件不存在 → 明确返回 nil 不崩。
8. **屏号失真**：itemAttrs 混入 screen=2 的旧屏号项（坐标在主屏范围）→ normalizeScreenIds 归入主屏。
9. **双写竞争**：两个写者同时写 conf（模拟）→ 原子写（tmp+rename）保证不出现半个 JSON。
10. **门禁矩阵**：token 错→401 / 网段外→403 / body>1MB→400 / items>500→400 / 坏 JSON→400 / 时间超前 300s→400，各一条实测。
11. **并发 POST**：10 并发写不同 syncAt → _state_lock 保证最终一致性，无交叉写坏。
12. **保护窗**：active 上报 vs 非 active 上报冲突 → 非 active 被拒 reason=protected。
13. **时钟偏移**：客户端钟落后 → clockOffset 补偿后上报成功。
14. **空布局拦截**：items=[] → 双向拦截（客户端拒发 + 中枢拒收）。
15. **40 点标定回归**：--selftest 120/120 吻合 + 变异测试（改 mapCell 一行 → selftest 必须变红）。
