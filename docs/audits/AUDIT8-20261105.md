## 五、本轮的自证价值

**「回滚编号错位」是最典型的隐蔽 bug**：
- 列表显示 #1 是 `20261106-044329-Studio(回滚).json`（42 项 ✅）
- 但回滚 #1 实际取到的是 `ls -t` 排序下的另一个文件 —— **两套排序规则不一致**
- 后果：用户以为回滚到了 A，实际回滚到 B；**回滚功能在最需要它的时候（中枢被污染）会回滚到错误对象**
- 修复后实测：列表 #1 = `20261106-044329-Studio(回滚).json` 42 项 fp `dcab6a889ee8` → 回滚后中枢 fp 精确吻合 ✓

**教训**：任何"给用户看的编号"和"实际取对象的逻辑"**必须共用同一个选择器**，
否则用户看到的和拿到的不一致 —— 这类 bug 不会有任何报错，只会造成"我明明选了 A 却回滚到 B"。
