## 三、本轮修复内容

### 1. 回滚脚本令牌（P1，最关键）

**根因**：第三次审计加共享密钥时，只改了 Swift 客户端，**漏了回滚脚本**。

**修复**：脚本头部读 `~/qspace-layouts/hub-token.txt`，5 处调用全部加头：
- `pick_hub()` 的 2 处探测（否则判定"中枢不可达"）
- `--check` / 列表页的 2 处 `curl /status`
- `--local` 与正式回滚的 2 处 `urllib POST /layout`

**实测**：
```
修复前: {"error": "unauthorized"}
修复后: {"ok": true, "hasLayout": true, ...}
端到端: 回滚 → 三台 25 秒内应用 → PASS
三台:   --check 全部 OK
```

### 2. HTTP 状态码可见（P2）

新增 `logHTTPCode(method, url, code, body)`，非 200 必落日志并翻译成人话：
```
401 → 令牌失效（hub-token.txt 与中枢不一致）
403 → 网段外被拒
400 → 数据被拒：<error>
404 → 中枢无该接口
```

### 3. 死代码调用点清零（P2）

- `autoSwitchIfNeeded()`（空）：2 处调用 → 改为 `runSyncCycle()`（切套由 `checkSpecChange` 统一处理）
- `monitorLayoutChanges()`（空）：3 处调用 + **「时光机监测」每 30 分钟空转块** → 整块移除
- 保留函数定义（带"已废弃"注释，防误删时找不到替代方案）

### 4. 版本号（P3）

`CFBundleVersion` → `2.0.6134`，启动日志打版本：
```

```
