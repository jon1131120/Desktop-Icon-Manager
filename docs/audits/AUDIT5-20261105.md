### 客户端为什么没崩（关键防御）

`applyRemoteIfNewer` 的类型转换是**天然兜底**：
```swift
guard let items = remote["items"] as? [[String: Any]], !items.isEmpty else { return }
```
垃圾数组转 `[[String: Any]]` 失败 → 静默跳过 → 不写坏本地 conf。
**但同步会中断**（拉到的永远应用不了），直到下一次合法上报。
