## 三、本轮修复内容

### 1. 中枢共享密钥（P1，最重要）

**威胁模型**：MINIPC 上跑着 8+ 个容器（homeassistant / grafana / emby / adb-panel / fence-hub …），
其中 host 网络模式的容器**源 IP = 宿主 IP**，网段白名单完全挡不住 → 容器内任意进程可
`POST /layout` 覆盖全机队桌面布局。

**修复**：叠加共享密钥（`hmac.compare_digest` 恒定时间比较）
```python
TOKEN_FILE = os.path.join(HUB, 'hub-token.txt')   # 权限 600
def token_ok(provided):
    exp = load_token()
    if not exp: return True          # 未配置 → 仅靠网段（首次启动过渡）
    return hmac.compare_digest(provided or '', exp)
```
客户端：`hubToken()` 读 `~/qspace-layouts/hub-token.txt` → `X-Hub-Token` 头

**四态实测**：
```
无 token  : 401 ✓
错 token  : 401 ✓
对 token  : 200 ✓
ZT + token: 200 ✓
```
