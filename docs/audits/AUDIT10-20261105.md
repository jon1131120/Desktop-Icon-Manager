## 五、clockOffset 机制的完整闭环（本轮验证）

```
场景 A: 本机时钟落后 N 秒
  上报 at=now → older 拒 → offset = cur+1-now → 下轮 at=now+offset > cur → 接受 ✓

场景 B: 本机时钟超前 N 秒（>300）
  上报 at=now → 400 future → 兜底 hubTime+1 重发 → 接受
  ⭐ 且更新 offset = hubTime+1-now → 下轮直接用正确 offset → 不再 400 ✓（本轮修复）

场景 C: 同秒碰撞
  上报 → older 拒 → pendingRepushFp + skipPullOnce → 下轮重推 at=now+offset → 接受 ✓

场景 D: 重推仍被拒（中枢又前进）
  pending == fp → 放弃 + baseline=fp → 拉取覆盖 → 最后一致 ✓
```

**四个场景全部闭环，无死循环、无丢失。**
