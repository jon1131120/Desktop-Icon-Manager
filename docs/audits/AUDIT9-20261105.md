## 四、本轮修复清单

### 1. 时钟偏移补偿（P2，最重要）
```swift
// 上报时
let clockOffset = st["clockOffset"] as? Int ?? 0
snap["syncAt"] = now + clockOffset

// 被拒时记录
if let latest = resp["latestSyncAt"] as? Int, latest > 0 {
    st["clockOffset"] = latest + 1 - now
}
```

**为什么必须修**：第八轮的重推机制假设"下轮 `now` 已更新"，但**若本机时钟整体落后中枢**（NTP 未同步/手工改时/RTC 漂移），下轮的 `now` 仍然落后 → 重推照样被拒 → **重推机制完全失效，改动永久丢失且无任何报错**。

**验证**（逻辑模拟）：
```
修复前: at=1000 vs cur=1010 → 拒绝 → 重推 at=1000 → 仍拒绝 → 死循环
修复后: offset=11 → at=1011 > 1010 → 接受 ✓
        连续 3 轮: 1011/1021/1031 vs 1010/1020/1030 → 全接受 ✓
        offset 超 300s → 400 future → hubServerTime 兜底 ✓
```
**三台实测**：`clockOffset=0`（时钟同步，无需补偿，机制待命）
