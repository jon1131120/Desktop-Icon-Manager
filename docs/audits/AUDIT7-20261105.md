## 五、自证：本轮我自己的操作失误

| 失误 | 教训 |
|---|---|
| 用 `syncAt=now+9` 做校验矩阵测试，正常请求被接受 → 污染中枢（`r7`，1 项） | **测试必须用「过去」的 syncAt**，让所有请求都走 `older` 拒绝路径，既能验证校验逻辑又不写脏数据 |
| 上次改 `microNudgeOn` 时只替换了第一行，留下 `? true : bool("microNudgeOff")` 尾巴 | **替换多行表达式必须看完整语句边界**，不能只替换首行；改完必须 grep 确认没有残留 |
| 删 `autoMonitorOn` 定义时没先查引用 → 编译失败 | **删变量前先 grep 全部引用**，一次删干净 |
