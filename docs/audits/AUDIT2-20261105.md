## 三、本轮修复内容

### 1. 空布局拦截（P1）
```swift
// broadcastIfNeeded 上报前
guard !gitems.isEmpty else {
    logLine("sync: 本机布局为空（0 个图标），拒绝上报以免清空中枢")
    return
}
```
**为何危险**：`fnv1a("")` 仍返回非空指纹，中枢会当作正常版本接收 → 全机队被清空。
**双向拦截**：中枢侧也已有 `items must be a non-empty array` → 实测 400 ✓

### 2. conf 损坏留痕（P2）
`loadConf` 解析失败时写日志；快照生成失败时写日志。

### 3. 中枢线程化（P2）
`HTTPServer` → `ThreadingHTTPServer` + `daemon_threads` + `HANDLER.timeout = 10`。

### 4. 本地快照恢复入口（P2）
```bash
~/qspace-layouts/qspace-rollback.sh --local        # 列出 archive-old
~/qspace-layouts/qspace-rollback.sh --local 3      # 从第 3 个恢复（自动按 lod 判套转格）
```

### 5. 配置残留清理（P3）
删除 `sleepLayout` / `wakeLayout` / `lastAutoSaveDay`。
